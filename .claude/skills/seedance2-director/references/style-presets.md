# Seedance Director Style Presets

These Seedance Director presets are positive-only style layers. Keep brand names in prompts as
style anchors, then describe the visual language. Do not ask for logos, trademarks, exact
packaging, proprietary UI, or exact brand replication unless the user explicitly provided licensed
assets.
