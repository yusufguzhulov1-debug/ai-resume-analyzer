# AI Resume Analyzer 🚀

An AI-powered resume analysis platform that helps job seekers improve their CVs using artificial intelligence.

## ✨ Features

- Upload resume files
- AI-powered CV analysis
- ATS compatibility score
- Skills evaluation
- Strength and weakness detection
- Career improvement recommendations
- Modern responsive interface

## 🛠 Tech Stack

Frontend:
- React
- JavaScript
- Tailwind CSS

AI:
- OpenAI API / Claude API

Tools:
- Vite
- GitHub
